# Projet AIS – Administration Linux Debian

## Présentation

Projet d'administration et de sécurisation de serveurs Linux Debian réalisé dans le cadre de ma formation Administrateur d'Infrastructures Sécurisées (AIS) chez O'clock.

Ce portfolio présente plusieurs travaux pratiques réalisés en environnement de formation.

## Objectifs du projet

- Installer et administrer un serveur Debian.
- Gérer les utilisateurs, groupes et permissions.
- Configurer l'administration à distance avec SSH.
- Déployer un contrôleur de domaine Samba Active Directory.
- Configurer les services DNS et Kerberos.
- Administrer et sécuriser les services Linux.

## Technologies utilisées

- Debian GNU/Linux
- Bash
- SSH
- Samba AD DC
- DNS
- Kerberos
- Apache2
- systemd
- Windows 11 et RSAT

## Réalisations techniques

### 1. Administration Linux

- Gestion des utilisateurs et des groupes.
- Configuration des droits d'accès avec `chmod` et `chown`.
- Gestion des privilèges administrateur avec `sudo`.
- Vérification des services avec `systemctl`.
- Consultation des journaux système.

### 2. Administration à distance avec SSH

- Configuration de l'accès SSH à un serveur Debian.
- Connexion à distance depuis Windows 11 avec PowerShell.
- Vérification de la connectivité réseau.
- Administration du serveur en ligne de commande.

### 3. Contrôleur de domaine Samba Active Directory

- Configuration d'un contrôleur de domaine Samba AD DC sous Debian.
- Configuration des services DNS et Kerberos.
- Vérification de l'authentification Kerberos avec `klist`.
- Intégration d'un poste Windows 11 au domaine de formation.
- Administration des objets Active Directory avec RSAT.

### 4. Sécurisation d'un serveur Linux

- Vérification et gestion des comptes utilisateurs.
- Verrouillage de comptes inutilisés.
- Contrôle des privilèges `sudo`.
- Configuration des permissions sur les dossiers partagés.
- Vérification du fonctionnement des services.

### 5. Services web et partages

- Administration du serveur web Apache2.
- Vérification de la configuration avec `apache2ctl configtest`.
- Configuration de partages Samba.
- Vérification de la configuration avec `testparm`.

## Bilan

Ces travaux pratiques m'ont permis de développer mes compétences en administration Linux, gestion des identités, services réseau et sécurisation des infrastructures.

Ils constituent une première expérience pratique dans le cadre de ma reconversion vers l'administration systèmes et réseaux.
